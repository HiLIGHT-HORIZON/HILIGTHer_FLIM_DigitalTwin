Mathematical model and code mapping

This page explains the model in plain English and then ties each concept back to the current Python implementation.

Latent optical model

Plain English

The Digital Twin starts from an idealised fluorescence decay, then shapes it with the laser profile and detector timing model before gates or bins collect photons.

For specialists

The latent timing model is built around dt_pdf(t, tau) and dt_excitation(t). The laser profile is the excitation envelope. Gate distillation converts that continuous timing model into gate-domain probabilities.

Fisher metrics

The desktop reports three related quantities: F=1I F-2=I where I is the Fisher Information for the chosen decay parameter under the chosen photon-basis convention.

F-value photon basis

Plain English

The same detector can be judged three ways: against all photons in the acquisition period, against all photons in the full period, or only against the photons that actually landed in the measured gates.

For specialists

The implementation uses three semantics: period-aware full budget, acquisition-window-aware full budget, and collected-only renormalisation. The collected-only mode is conditional on measured photons and does not penalise gated-out counts.

Throughput and AUC objectives

The optimisation framework supports instantaneous and area-under-curve throughput-style objectives. Under fixed dose, throughput changes come from information efficiency and detection losses. Under fixed peak, throughput can also increase because the area under the excitation profile is allowed to grow.

Phasors

The phasor coordinates are computed internally from the gated or binned signal, calibrated with the same laser profile used by the decay model. The widget displays both the universal semicircle and the discrete single-exponential locus implied by the actual gate set.

Optimisation maths

Detection optimisation can be direct, partition-based, or Fisher-compression-based. Fisher Compression also supports nuisance-aware Schur-complement scoring.
