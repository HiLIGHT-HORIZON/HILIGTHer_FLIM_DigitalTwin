Workflow

2D MC tests and MC Image validation

This workflow generates validation images, fits them, and exposes per-pixel diagnostics. It is used to test full image-analysis behaviour rather than one-dimensional Fisher curves.

Pixel analysis flow

Plain English

Clicking a pixel shows the measured decay, the fitted decay, residuals, and the exact laser profile used to fit that pixel.

For specialists

The backend produces validation images with known truth, then the fit path computes dense reconvolved curves for display while keeping residuals grounded in the actual binned or gated prediction.

Phasor flow

Plain English

The phasor view gives a compact summary of pixel behaviour in a frequency-domain representation. Selecting a pixel in the image also highlights its phasor.

For specialists

The current phasor implementation is internal to the HILIGHTer backend. It uses the known laser profile for calibration and plots both the universal semicircle and the discrete single-exponential locus implied by the actual gate scheme.

Fitting methods

The main lifetime-fitting options exposed in the desktop are Gridded MLE, Iterative Reconvolution, and Tail Fitting. Tail Fitting starts after the laser profile has fallen by the configured 3-sigma criterion.
