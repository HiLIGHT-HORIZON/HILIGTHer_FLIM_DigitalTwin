API

Programmatic APIs

The Digital Twin exposes one orchestration layer and multiple transports. The Python service API is the source of truth. The HTTP API and the MCP server both sit on top of it.

Python service API

Plain English

If another Python process wants to control the Digital Twin directly, this is the easiest layer to call.

For specialists

python/backend/service_api.py exposes DigitalTwinService methods such as get_status(), update_config(), run_precision(), run_optimization(), run_validation_image(), fit_validation_image(), and session/profile helpers.

GUI schema API

The GUI schema is a machine-readable description of the desktop workspace. It is used for automation, front-end mirroring, and MCP-guided navigation.

Typical API examples

GET /api/v1/backend/status
GET /api/v1/backend/config
POST /api/v1/backend/config
{
  "config_patch": {
    "timing_jitter": 85.0,
    "detector_deadtime": 45.0
  }
}
POST /api/v1/workflows/precision
{
  "config_patch": {
    "precision_validate_mc": true,
    "precision_mc_repeats": 200
  }
}
POST /api/v1/workflows/optimisation
{
  "config_patch": {
    "optimize_detection_gates": true,
    "detection_optimization_algorithm": "fisher_compression"
  }
