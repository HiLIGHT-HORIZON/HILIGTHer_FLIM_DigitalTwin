Overview

HILIGHTer Digital Twin documentation set

This manual is the main operator and engineering reference for the Python Digital Twin. It is deliberately split into multiple pages so that users can read the system in layers: plain-English workflow guidance first, specialist details next, and implementation notes directly tied to the actual codebase.

Desktop-first
Qt workspace for simulation, validation, optimisation, reports, and profiles.
API-complete
Python service API, HTTP API, desktop automation, and MCP share one backend engine.
Engineering-focused
Physics, Fisher analysis, Monte Carlo validation, and design optimisation are all documented with maths and code references.

Getting started

Plain English

If you are new, start the desktop with python\run_desktop.bat. The left column is the Digital Twin Controller. The right side shows the main outputs: precision, estimator accuracy, diagnostics, image validation, and pixel-level analysis. Use this manual to understand what each control means before changing instrument settings aggressively.

For specialists

The active product is the Python workspace rooted in python/. The core engine is python/backend/twin_engine.py. Controller state is represented by PhysicsConfig in python/backend/models.py. All documented workflows should be reproducible through the service layer in python/backend/service_api.py.

# Desktop
python\run_desktop.bat

# HTTP API
python -m uvicorn python.backend.main:app --reload

# MCP smoke test
python python/tools/mcp_smoke_test.py

Support widget and Ctrl+H

Plain English

Press Ctrl+H in the desktop app to open the support widget. It is a floating manual browser with home, back, forward, reload, and manual-search controls. The controller tabs also emit context jumps so the help window can open the relevant manual area while you work.

For specialists

The support widget is python/gui/widgets/manual_viewer.py. It now targets docs/manual/index.html and routes context identifiers such as controller, simulation, math, and fisher to specific manual pages and anchors.
