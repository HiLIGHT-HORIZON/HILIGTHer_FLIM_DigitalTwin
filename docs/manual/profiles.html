Profiles

Instrument profiles

Profiles are saved controller states representing complete instrument definitions. They are useful for reproducibility, sharing, and switching between reference systems such as TCSPC and gated cameras.

Profile JSON format

Plain English

A profile JSON stores the same essential settings that the controller holds in memory. It is a portable instrument preset.

For specialists

Profiles are managed through InstrumentProfileStore and are essentially persisted PhysicsConfig objects plus descriptive metadata.

Repair and sanitise

If a saved profile is missing new keys or contains obsolete keys, the profile manager can repair it. The repaired JSON is written back to disk before application, so the same profile is clean the next time it is opened.

Apply and preview

Clicking a profile shows compatibility information and a diagnostics preview in the floating manager window. Applying a profile now atomically updates the workspace config instead of relying on partial live widget mutation.

MCP-assisted profile creation

The MCP tool ingest_instrument_profile_source can extract a profile proposal from a PDF, HTML page, or local text source, then save and apply the resulting profile. See MCP for examples.
