  • Replicated well: the 8-gate reference and 4-gate baseline curves align closely with the report targets.
  • Partially replicated: the burst-width trend is broadly correct, but the Python sweet spot is closer to 5 ns than 7.5 ns.
  • Not replicated: the jitter/skewness figure is effectively flat in the current Python backend for rectangular excitation, unlike the MATLAB report.
  • Needs investigation: one optimised 4-gate configuration reproduces the target efficiency at 2 ns but shifts the peak lifetime substantially.

The current Python backend is therefore not yet a full parity match to the MATLAB/report results.
